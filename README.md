# Star Wars FFG · Monk's TokenBar

Аддон позволяет ведущему запросить проверку навыка у нескольких токенов и увидеть нарративные символы каждого броска в карточке Monk's TokenBar. Поддерживаются Foundry VTT 14, Monk's TokenBar 14.01 и система `starwarsffg` из ветки `v14-ru`.

## Установка

1. Установите систему Star Wars FFG и модуль Monk's TokenBar.
2. В установщике модулей Foundry вставьте ссылку в поле URL манифеста и нажмите «Установить».

   ```text
   https://raw.githubusercontent.com/DarkReef/StarWars-FFG-MonkTokenBar-Addon/main/module.json
   ```

3. В игровом мире включите оба модуля и перезагрузите мир.

## Проверка навыка

Чтобы запросить проверку у персонажа без токена на сцене, в окне запроса введите имя в поле «Найти актёра по имени» и выберите строку в списке «Добавить актёра из каталога». При одном совпадении можно нажать Enter. Удаление строки из окна исключает персонажа из текущего запроса.

Выделите токены, нажмите кнопку запроса броска на панели Monk's TokenBar и выберите навык. Выберите сложность от элементарной до чрезвычайно сложной. При средней сложности используются две фиолетовые кости. Порог успеха задаётся отдельно и по умолчанию равен одному чистому успеху.

В разделе «Изменить набор костей» можно добавить кости усиления, помехи или Силы, повысить способность или сложность. Например, у сложной проверки три фиолетовые кости. Одно повышение сложности заменяет одну из них красной. В строке каждого получателя сразу виден его набор с учётом ранга навыка и поправок. После отправки владелец персонажа или ведущий может выполнить бросок из этой строки в чате. Уровни сложности приведены на с. 25–26 «Силы и судьбы», повышение костей — на с. 30.

Пул учитывает характеристику, ранг навыка и его модификаторы, включая ранги группы приспешников. В чате видно, какую сложность назначил ведущий. После подтверждения броска у каждого участника появляется его фактический набор костей с учётом поправок в последнем окне.

Одного оставшегося успеха достаточно для успешной проверки. Преимущества и угрозы определяют сопутствующие последствия. Например, при одном успехе и двух угрозах персонаж выполняет действие, а ведущий расходует две угрозы. Триумф, отчаяние и результаты кости Силы видны отдельно. Если ведущий указал дополнительный порог успехов, карточка отдельно показывает, достигнут ли он. В истории бросков, сделанных до версии 0.3.1, доступны сохранённые символы. Фактический состав старых пулов восстановить по ним нельзя.

## Состязание двух токенов

Кнопка встречного броска Monk's TokenBar создаёт **два отдельных броска** с выбранной общей сложностью. Для каждой стороны можно указать свой навык. TokenBar сравнивает чистые успехи и отмечает на карточке одинаковые результаты как ничью. Триумфы и преимущества видны отдельно, поэтому ведущий может учесть их при разборе ничьей. Для проверки противодействия по правилам FFG, где навыки соперника задают фиолетовые и красные кубики в одном пуле, используйте редактор пула системы. Там же доступны ручная сборка пула и броски оружия.

## Пример для макроса

```js
await game.MonksTokenBar.requestRoll(canvas.tokens.controlled, {
    request: "skill:perception",
    ffgDifficulty: 3,
    ffgModifiers: { boost: 1, upgradeDifficulty: 1 },
    rollMode: "gmroll",
    silent: true
});
```

`ffgDifficulty` задаёт число кубиков сложности. `dc` задаёт порог чистых успехов. Идентификаторы навыков в макросах пишутся строчными буквами. Для составного имени используйте кодирование, например `skill:piloting%3a%20space`. Карточка хранит итог броска. Чтобы перебросить нарративный пул, создайте новый запрос.
